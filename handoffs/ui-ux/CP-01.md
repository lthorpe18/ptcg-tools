## Bounded deliverable

1. Define one token file for colour, type, spacing, borders, density and focus.
2. Build reusable compact toolbar, row, disclosure, filter surface, card inspector and state styles. Use semantic controls and keyboard/focus behaviour.
3. Implement ArtworkHeader: shallow full-width horizontal illustration, name overlaid only, focal-point support and stable fallback. No solid metadata/title panel below. Reuse canonical image/sprite APIs through a narrowly tested adapter; no second provider resolver.
4. Make a labelled read-only specimen with long names, realistic card rows, empty/error/loading and expanded/collapsed states. Avoid fake live collection figures.
5. Establish four-area interim preview navigation (Home/Meta/Decks/Compete), Utilities and Settings access; reserve Collection extension point without a dead tab.
6. Centralise route ownership and return-context handling. Unmigrated destinations explicitly open existing V2 features; do not wrap the V2 shell inside V3 or show non-working fake feature pages.
7. Check direct reload, back/forward, legacy return and safe-area behaviour. Document remaining feature adapters for CP02. Do not start a second account-sync owner.
8. Inspect actual browser layouts at 390px, 360px and desktop, plus enlarged text and keyboard. Record screenshots/observations and any unavailable device acceptance. No claim of visual verification from source parsing.
