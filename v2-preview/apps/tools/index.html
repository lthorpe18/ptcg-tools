Tournament

Cut / ID Calculator

Deterministic one-round ID check. No hidden tie-rate or simulation assumptions.

Without pairing data, every supplied player is conservatively allowed to gain 3 points. Complete known pairings tighten the bound because paired players cannot both win; known IDs are fixed at +1/+1. The calculator validates that the full field is represented before it can call an ID guaranteed. A tiebreak result means points alone cannot guarantee the cut.
